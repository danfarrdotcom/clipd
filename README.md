# Clipd

A lightweight, native macOS menu bar app for recording your screen as GIFs.

## Features

- Record any region of your screen
- Menu bar app — always accessible, no dock icon
- ScreenCaptureKit for high-performance capture

## Requirements

- macOS 13.0 or later
- Apple Silicon (arm64)

## Building

```bash
make build
```

## Usage

```bash
make run
```
