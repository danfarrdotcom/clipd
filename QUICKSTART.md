# Clipd TestFlight Quick Start

## 5 Minutes to Beta

### 1. Build & Archive (2 min)
```bash
open Clipd.xcodeproj
# Product > Archive
```

### 2. Upload (1 min)
```bash
# In Organizer: Distribute App > App Store Connect > Upload
# Or: fastlane beta
```

### 3. Add Testers (1 min)
```bash
# App Store Connect > Clipd > TestFlight > Internal Testing
# Add your email
```

### 4. Install (1 min)
```bash
# Open TestFlight app on Mac
# Click Install on Clipd
```

Done! 🎉
