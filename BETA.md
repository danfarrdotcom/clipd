# TestFlight Beta Testing

## Join the Beta

1. Download **TestFlight** from the Mac App Store
2. Accept the invitation email from Apple
3. Install **Clipd Beta**
4. Report feedback directly in TestFlight

## Beta Features

Current beta builds include upcoming features before App Store release:
- New recording modes
- Performance improvements
- UI refinements

## Feedback

Use TestFlight's built-in feedback tool (screenshots + notes) or open a GitHub issue.

## Auto-Updates

TestFlight automatically updates to new beta builds. You can also enable automatic updates in TestFlight settings.
