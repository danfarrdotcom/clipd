# GitHub Actions Setup

## Required Secrets

| Secret | Description |
|--------|-------------|
| APPLE_ID | Apple developer account email |
| TEAM_ID | Apple development team ID |
| ITC_TEAM_ID | App Store Connect team ID |
| APP_STORE_CONNECT_API_KEY_KEY_ID | API key ID |
| APP_STORE_CONNECT_API_KEY_ISSUER_ID | API key issuer ID |
| APP_STORE_CONNECT_API_KEY_KEY | Base64-encoded API key |
